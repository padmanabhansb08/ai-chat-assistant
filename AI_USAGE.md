## Engineering decisions
- Clean layering (presentation / domain / data) with get_it for DI.
- SQLite over Hive: relational messages-by-conversation with cascade delete and an index.
- API key in secure storage, never in the DB or source control.
- Gemini and OpenAI-compatible protocols behind one `AiRemoteDataSource` interface, routed by `ProviderType`.
- `ChatState` is one class with a status enum so messages survive loading and errors.
- `droppable()` on send for duplicate-request protection inside the Bloc.
- Retry reuses the stored user message (`persistUserMessage: false`) so a failed send never duplicates history.
- Typed `Failure`s mapped from HTTP status codes in one place (`core/network/http_guard.dart`).
